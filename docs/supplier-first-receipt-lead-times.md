# 供应商首收交期说明（ERP-109）

## 1. 定位

采购订单页新增一个**只读派生**的「供应商首收交期」报表，用既有入库单上的显式
`StockIn.PurchaseOrderId` 链接，统计每张已审核采购订单「订单日期（`PurchaseOrder.OrderDate`）→
首张有效已审核入库（`StockIn.StockInDate`）」的间隔天数，帮助运营按供应商 / 订单日期快速查看
首收快慢。

> **边界（重要）**：本报表是采购订单的**首收间隔视图**，不是完整交付完成度，也不是准时率 / 供应商
> 绩效考核。它不写任何表、不执行迁移 / 生产 SQL / 真实数据库操作 / 部署，也**不改写**采购订单、入库单、
> 库存与库存成本。缺失或不一致的日期一律按「未知 / 异常」呈现，绝不当作 0 或正常。

## 2. 接口

- `GET /api/purchase-orders/first-receipt-lead-times?supplierId=&orderDateFrom=&orderDateTo=&keyword=&page=&pageSize=`
  - 只筛选「未删除且已审核」的采购订单。
  - 有界分页（`pageSize` 1~200，默认 50），稳定排序（供应商 → 订单日期 → 单据 Id）。
  - `supplierId` / `orderDateFrom` / `orderDateTo`（含当天）/ `keyword`（采购单号 / 合同号 / 归属销售订单号）可选筛选；
    订单日期区间倒置直接返回参数错误。
  - 固定次数数据集访问（无逐单查库），批量装载本页关联入库单。

## 3. 首收口径（后端、前端与测试同源）

| 状态值 | 含义 | 判定 |
| --- | --- | --- |
| `received` | 已派生 | 存在最早「以本单为来源、未删除、已审核、供应商与本单一致」的入库，间隔 ≥ 0 |
| `negative_interval` | 负间隔（异常） | 首张有效入库早于订单日期，间隔为负（保留负值，不钳制为 0） |
| `unavailable` | 未知 | 无有效入库证据，或入库证据超过单次派生上限（2000 张） |

- 首收日期 = 最早一张 `StockIn.PurchaseOrderId` 指向本单、`IsDeleted == false`、
  `Status == Approved`、`SupplierId` 与本单一致的入库日期。
- 间隔天数 = 首收日期 − 订单日期（整数天）。
- 未审核 / 已删除 / 供应商不一致 / 早于订单日期的入库**仅作异常证据列出、不计入首收**；
  负间隔不静默钳制为 0，而是显式标注为异常。

## 4. 异常证据口径（不计入首收，仅标注）

- 未审核入库（`Status != Approved`，如待提交 / 已提交 / 已驳回 / 已取消）。
- 已删除入库（`IsDeleted == true`）。
- 供应商不一致入库（`SupplierId` 与本单不一致）。
- 早于订单日期的入库（首张有效入库 `StockInDate < OrderDate`）。
- 本页关联入库单超过单次派生上限（2000 张）时，无法保证取到最早入库，整页首收日期按未知返回。

## 5. 界面

采购订单页工具栏「⏱️ 首收交期」打开报表：供应商 / 订单日期区间 / 关键字 / 每页条数筛选，
KPI（已审核订单数、已派生首收、负间隔 / 未知 / 异常本页计数）、订单明细表（采购单号链接、订单日期、
单据状态、供应商、首收入库单链接、首收日期、间隔天数、首收状态、异常、说明）与 CSV 导出。
未知值在表格与导出中原样显示「未知」，负间隔显示为负天数。

## 6. 测试

`src/ERP.UnitTests/SupplierFirstReceiptLeadTimeTests.cs` 覆盖：多张入库取最早有效入库、缺链接未知、
未审核 / 已删除 / 供应商不一致入库不计入首收、负间隔不钳制、只筛选已审核订单并按供应商 / 日期过滤、
分页有界与稳定排序、批量取数（固定次数数据集访问、无逐单查库）、只读不写库、接口端点与前端接线契约。
全部使用内存数据库，不连接 SQL Server、不启动 API、不执行任何 SQL 或 seed。
