# 业务员数据范围（ERP-097）

## 1. 定位

为**客户与销售单据**（客户、询价单、报价单、PI、销售订单、销售出库、客户销项发票）增加统一的**服务端数据范围**：
受限制的业务员只能看到「自己被分配的客户」及其相关销售单据，特权账号保留既有全部访问。

- 唯一权威口径：`src/ERP.Application/Services/SalespersonDataScopeService.cs`（`ResolveAsync` / `FilterByCustomer` / `AllowsCustomer`）。
- 每次请求**重新解析**（授权 / 员工 / 客户分配变更后立即收敛，绝不缓存）。
- **只读现有表**（`SysUsers` / `SysRoles` / `SysUserRoles` / `SysParameters` / `BaseEmployees` / `BaseCustomers`），
  **不新增任何表或列**，不引入新的权限模型。

## 2. 特权判定（保留既有访问）

满足任一条件即视为**特权账号**（不过滤）：

1. 拥有「超级管理员」角色（角色编码 `SuperAdmin`）；
2. 拥有任一系统内置角色（`SysRole.IsSystem == true`）；
3. 拥有出现在系统参数 `DataScopePrivilegedRoles`（逗号分隔的角色编码）中的角色 —— 这是「显式特权角色」的可配置入口，
   默认（未配置）仅超级管理员。

## 3. 业务员映射（受限制账号）

受限制账号按其**登录账号 == 员工编码**映射到业务员：

- `SysUser.UserName`（去首尾空白）精确匹配 `BaseEmployee.EmployeeCode`，且该员工 `IsSalesman == true`；
- 可见客户 = `BaseCustomer.EmpId == 本人员工 Id` 的客户；
- 未映射到业务员时可见客户集合为**空**（fail closed：看不到任何客户）。

## 4. 端点行为

| 维度 | 行为 |
|---|---|
| 列表（GetPaged / GetAll） | 特权不过滤；受限制业务员只返回其客户相关记录 |
| 详情（GetById / GetPrint） | 越界记录按「不存在」`NotFound` 拒绝（fail closed，不披露存在性） |
| 导出（询价单导出 / 销售订单 Excel 导出） | 与列表同口径过滤，绝不导出越界记录 |

覆盖控制器：`CustomerController`、`InquiryController`、`QuotationController`、`ProformaInvoiceController`、
`SalesOrderController`、`StockOutController`（shipment）、`CustomerSalesInvoiceEvidenceController`（invoice）。
