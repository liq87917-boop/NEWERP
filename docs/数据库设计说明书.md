# 外贸 ERP 系统 · 数据库设计说明书

> 数据库：WMERP_Data · SQL Server 2022 · 所有表继承审计基类字段：`Id`(bigint 自增主键)、`CreatedAt`、`CreatedBy`、`UpdatedAt`、`UpdatedBy`、`IsDeleted`(软删除)、`RowVersion`(并发令牌)

## 一、系统设置模块（Sys_ 前缀）

### 1. SysUser 系统用户
| 字段 | 类型 | 说明 |
|---|---|---|
| UserName | nvarchar(50) | 登录账号（唯一索引） |
| PasswordHash | nvarchar(256) | 密码哈希（PBKDF2） |
| PasswordSalt | nvarchar(64) | 密码盐 |
| DisplayName | nvarchar(50) | 显示姓名 |
| Email / Phone | nvarchar | 邮箱/手机 |
| Status | int | 1启用/0禁用 |
| LastLoginTime / LastLoginIp | — | 最近登录 |
| MustChangePassword | bit | 首次登录强制改密 |

### 2. SysRole 角色
RoleName、RoleCode(唯一)、Description、IsSystem(内置角色)

### 3. SysUserRole 用户角色关联
UserId、RoleId

### 4. SysMenu 菜单/权限
ParentId、MenuName、MenuCode(唯一)、Path、Icon、SortOrder、MenuType(1目录/2菜单/3按钮)、PermissionCode

### 5. SysRoleMenu 角色菜单关联
RoleId、MenuId

### 6. SysParameter 系统参数
ParamKey(唯一)、ParamValue、ParamName、Description、IsSystem

### 7. SysUserParameter 用户参数
UserId、ParamKey、ParamValue

### 8. SysDocumentNumberRule 单据号规则
DocumentType、RuleCode(唯一)、RuleName、Prefix、DateFormat、SerialLength、Separator、CurrentSequence、YearlyReset、Remark

### 9. SysClientLimit 客户端限制
LimitType(1 IP/2 机器码)、LimitValue、IsEnabled、Remark

### 10. SysOperationLog 系统日志
UserId、UserName、Module、Action、Method、Path、**BillNo（单据号，第四阶段新增，用于按单据追溯）**、RequestBody、IpAddress、StatusCode、DurationMs

### 11. SysPrintTemplate 打印模板（第四阶段新增，打印设计）

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | BIGINT IDENTITY | 主键 |
| BillType | NVARCHAR(50) | 单据类型（等于菜单编码，如 sales-order / customer） |
| TemplateName | NVARCHAR(100) | 模板名称（同一单据类型内唯一） |
| Title | NVARCHAR(200) | 打印标题（为空时取单据中文名） |
| CompanyName / CompanyAddress / CompanyPhone | NVARCHAR | 打印页眉公司抬头信息 |
| ShowCompanyHeader | BIT | 是否打印公司抬头 |
| ShowDetailTable | BIT | 是否打印明细（副表） |
| ShowRemark | BIT | 是否打印备注 |
| PaperSize | NVARCHAR(20) | 纸张规格：A4 / A5 / A4-L（横向）/ 80mm |
| FontSize | INT | 正文字号（8–24 px） |
| FieldKeys | NVARCHAR(2000) | 打印字段顺序（JSON 数组，如 `["BillNo","OrderDate"]`） |
| FooterText | NVARCHAR(500) | 页脚文本 |
| IsDefault | BIT | 是否该单据类型的默认模板（同类型仅一个默认） |
| CreatedAt / CreatedBy / UpdatedAt / UpdatedBy / IsDeleted / RowVersion | — | 审计字段（继承自实体基类） |

> 唯一索引：`UX_SysPrintTemplates_BillType_Name (BillType, TemplateName)`；
> 无模板时接口返回内置默认配置（公司名称取系统参数 `CompanyName`）。

## 八、第四阶段新增（销审 / 打印 / 导入 / 日志追溯）

| 内容 | 说明 |
|---|---|
| 销审（UnAudit） | 全部 16 个 `sp_Biz_*` 存储过程新增 `@Action='UnAudit'` 分支：仅「已审核(Status=2)」单据可销审，销审后回退为「保存(Status=1)」 |
| 单据状态流转校验 | API 在调用存储过程后回读 `Status` 校验流转是否生效，未执行升级脚本时返回明确提示 |
| 打印模板表 | `db_owner.SysPrintTemplates`（见 1.11），支持每单据类型多模板 + 默认模板 |
| 操作日志追溯 | `db_owner.SysOperationLogs` 新增 `BillNo` 列；单据的新增/保存/审核/销审/作废/还原/删除均由 `BillProcController` 显式写入日志 |
| 升级脚本 | `deploy/init4.sql`（幂等）：重建 16 个 `sp_Biz_*`（CREATE OR ALTER）+ 建打印模板表 + 加日志列 |

> 应用启动时另会执行 `SchemaUpgrader`（`IF NOT EXISTS` 方式补齐新增表与列），因此**结构与表的升级无需人工执行 DDL**；
> 但存储过程内的销审分支必须执行 `deploy/init4.sql`（或重新执行 init2/init3 后再执行 init4）才能生效。

## 九、索引策略

- 所有编码/单号字段均建立**唯一索引**（防止重复）。
- 外键字段（CustomerId、SupplierId、ProductId、WarehouseId 等）建议建立普通索引。
- 明细表外键配置**级联删除**（主表删除时自动清理明细）。
- Stock 表 `(WarehouseId, ProductId)` 联合唯一索引。
- 软删除字段 `IsDeleted` 与查询条件结合，所有查询自动过滤已删除数据。
