# 外贸 ERP 系统 · 数据库设计说明书

> 版本：V1.1 · 日期：2026-09-23 · 补正任务：**ERP-017**（文档补正）
>
> **口径说明**：第一 ~ 九节为 2026-08/09 已交付的基线结构；**第十 ~ 十四节**为阶段 1~3 与 **ERP-007/008/009/010** 审计后补记的表与列。文中所有"新增"均指应用启动时由 `SchemaUpgrader.EnsureUpgradedAsync` **幂等**补齐（`OBJECT_ID` 建表 + `COL_LENGTH` 补列）并在 `deploy/init*.sql` 中留有对应脚本，**不代表已对生产库执行**：生产库上线、发布与不可逆操作仍受 Human Gate 控制，本节只记录代码级结构，不声明任何生产迁移结论。

## 九、索引策略

- 所有编码/单号字段均建立**唯一索引**（防止重复）。
- 外键字段（CustomerId、SupplierId、ProductId、WarehouseId 等）建议建立普通索引。
- 明细表外键配置**级联删除**（主表删除时自动清理明细）。
- Stock 表 `(WarehouseId, ProductId)` 联合唯一索引。
- 软删除字段 `IsDeleted` 与查询条件结合，所有查询自动过滤已删除数据。
