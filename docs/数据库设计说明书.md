# 外贸 ERP 系统 · 数据库设计说明书

> 版本：V1.1 · 日期：2026-09-23 · 补正任务：**ERP-017**（文档补正）
>
> **口径说明**：第一 ~ 九节为 2026-08/09 已交付的基线结构；**第十 ~ 十四节**为阶段 1~3 与 **ERP-007/008/009/010** 审计后补记的表与列。文中所有"新增"均指应用启动时由 `SchemaUpgrader.EnsureUpgradedAsync` **幂等**补齐（`OBJECT_ID` 建表 + `COL_LENGTH` 补列）并在 `deploy/init*.sql` 中留有对应脚本，**不代表已对生产库执行**：生产库上线、发布与不可逆操作仍受 Human Gate 控制，本节只记录代码级结构，不声明任何生产迁移结论。

## 九、索引策略

- 所有编码/单号字段均建立**唯一索引**（防止重复）。
- 外键字段（CustomerId、SupplierId、ProductId、WarehouseId 等）建议建立普通索引。
- 明细表外键配置**级联删除**（主表删除时自动清理明细）。
- Stock 表 `(WarehouseId, ProductId)` 联合唯一索引。
- 软删除字段 `IsDeleted` 与查询条件结合，所有查询自动过滤已删除数据。

## 二十、供应商采购发票登记（普票 / 专票证据 + 可选采购订单关联）（ERP-043）

**定位**：新增**供应商采购发票登记册**，登记**普通发票（普票）/ 增值税专用发票（专票）**的运营证据，并可（可选、显式）把含税总额的**全部或一部分**关联到既有采购订单。它是**操作性证据台账**，**不是应付账款台账、不是税务申报系统、也不是付款授权机制**；不引入第二套账务引擎（不记账、不生成凭证 / 收款 / 付款 / 结算单），登记 / 作废都不改写采购订单、库存与库存成本、库存流水、退税记录、供应商余额与付款状态。完整口径见《供应商采购发票登记说明.md》。

| 项 | 口径 |
|---|---|
| 表 | `PurchaseInvoices`（发票证据）、`PurchaseInvoiceAllocations`（发票 → 采购订单 关联行）：`SchemaUpgrader` 第 31 段 `IF OBJECT_ID(...) IS NULL` 幂等建表 + 建索引 / 外键，**不含任何 `UPDATE` / `INSERT` 回填语句** |

| 外键 | 唯一外键是「关联行 → 发票」（级联，发票仍只做软删除）；**刻意不建**到采购订单 / 供应商的外键，也不在采购订单上加任何列或导航属性 —— 订单软删除 / 取消、供应商停用 / 改名都不影响历史证据可读 |
