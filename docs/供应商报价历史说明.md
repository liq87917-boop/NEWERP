# 供应商报价价格历史（ERP-098）

## 1. 目的

为已持久化的采购报价（`PurchaseQuote`）提供一个**只读**的比价历史工作台：按商品展示历史报价，
仅在相同比价口径内计算价格差异，帮助采购人员横向比价、核对审批 / 选中证据，
但**不自动选择供应商、不修改报价 / 订单 / 价格**。

## 2. 边界（重要）

- **只读**：不写库、不改价格、不改报价 / 采购订单 / 库存 / 收付款，不自动选择供应商。
- **审批 / 选中仅作证据回显**：来自 `PurchaseQuoteDecision`（ERP-095，append-only），
  不代表本视图自动推进任何业务状态。
- **不做汇率换算、不合并不同币种金额**：价格差异只在相同口径内计算。

## 3. 比价口径

同一商品的报价行，仅当以下四项**完全一致**时才视为同一比价口径、可横向比价：

| 字段 | 说明 |
|---|---|
| 规格 Spec | 未填写按「未填」归组 |
| 单位 Unit | 未填写按「未填」归组 |
| 币种 Currency | 不区分大小写 |
| 是否含税 TaxIncluded | 含税 / 不含税 |

口径不一致的报价行按口径**分组成行单列**，绝不跨口径比较价格；不同币种金额绝不合并。

## 4. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/purchase/quotes/price-history` | 通用查询：按 `productId`（必填）+ 可选 `supplierId` / `dateFrom` / `dateTo` / `referenceQuoteId` / `page` / `pageSize` 筛选 |
| GET | `/api/purchase/quotes/{id}/price-history` | 从某个比价行打开：以该行商品为筛选商品、该行口径为参照口径 |

两者都：

- 排除软删除（`IsDeleted`）行；
- 按「报价日期 + 行 Id」稳定排序；
- 分页有界（默认 50、上限 200），命中截断时显式返回 `truncated=true`；
- 无匹配时返回显式 `emptyText`。

## 5. 响应要点

- `groups[]`：按比价口径分组，每组合 `basisText`、`comparable`（是否与参照口径一致）、
  `minPrice` / `maxPrice` / `latestPrice` / `priceSpread` 与 `rows[]`。
- 每一行保留供应商、币种、单位、规格、含税、数量、报价单价 / 总额、交期、MOQ、付款条件、
  选中状态、状态、审批状态（Approved / Rejected / Pending）、决定人 / 决定依据 / 审批参考号。

## 6. 前端

- 供应商比价页行操作新增「📊 报价历史」（`modules.js` → `purchase-quote-price-history.js`）。
- 点击后调用 `GET /api/purchase/quotes/{id}/price-history`，在弹层中按口径分组展示，
  可同比价组标注「🟢 可同比价」，口径不同组标注「🟡 口径不同（仅单列，不参与比价）」。

## 7. 验证

单元测试 `src/ERP.UnitTests/PurchaseQuotePriceHistoryTests.cs`（内存数据库，不连接 SQL Server、不启动 API）覆盖：
分组、组内价格差异、供应商 / 日期筛选与软删除、稳定排序、分页有界与截断、审批选中上下文回显、
无写入语义、参数校验与接口路由契约。
