# 客户销项发票收款时效证据说明（ERP-111）

## 1. 定位

客户销项发票页新增一个**只读派生**的「收款时效证据」视图，用既有 ERP-073「客户收款单 → 客户销项发票」
的显式分摊行，统计每张**已登记**发票「开票日期（`CustomerSalesInvoiceEvidence.InvoiceDate`）→
首张 / 末张有效收款日期（`FinanceReceipt.ReceiptDate`）」的间隔天数，并展示可比较的已分摊 / 剩余证据。

> **边界（重要）**：本视图是发票的**收款时效证据视图**，**不是**银行到账凭证、**不是**法定账龄、
> **不是**催收 SLA、**不是**收入确认或结算确认。它不写任何表、不执行迁移 / 生产 SQL / 真实数据库操作 / 部署，
> 也**不改写**发票、收款单、分摊行、客户。分摊行**绝不**被解释为已付 / 已结清 / 逾期 / 已确认收入 / 已记账状态。

## 2. 接口

- `GET /api/customer-sales-invoices/collection-timing?customerId=&invoiceDateFrom=&invoiceDateTo=&keyword=&page=&pageSize=`
  - 只筛选「未删除且已登记」的客户销项发票证据。
  - 有界分页（`pageSize` 1~200，默认 50），稳定排序（客户 → 开票日期 → 单据 Id）。
  - `customerId` / `invoiceDateFrom` / `invoiceDateTo`（含当天）/ `keyword`（发票号码 / 发票代码 / 客户编码 / 客户名称）可选筛选；
    开票日期区间倒置直接返回参数错误。
  - **应用业务员数据范围**（ERP-097 唯一权威口径）：受限制业务员只能看到自己被分配客户的发票。
  - 固定次数数据集访问（无逐单查库），批量装载本页关联分摊行与收款单。

## 3. 收款时效口径（后端、前端与测试同源）

| 概念 | 判定 |
| --- | --- |
| 有效收款 | 未作废分摊行（`Status == 1`）+ 收款单存在、未删除且未取消 + 币种与发票一致 + 收款日期不早于开票日期 |
| 首张有效收款 | 有效收款中 `ReceiptDate` 最早（同日按收款单号、分摊行 Id 稳定排序） |
| 末张有效收款 | 有效收款中 `ReceiptDate` 最晚 |
| 首收 / 末收间隔天数 | 收款日期 − 开票日期（整数天；只对有效收款计算） |
| 可比较已分摊 | 有效收款分摊金额合计（原币） |
| 可比较剩余 | 含税总额 − 可比较已分摊（下限 0；只作算术证据，不代表应收余额） |

## 4. 异常证据口径（仅标注、不计入首末收款与可比较金额）

- 缺收款单（收款单不存在或已删除）。
- 已作废分摊行（`Status == 2`）。
- 收款单已取消（`Status == Cancelled`）。
- 早于开票日期的收款（`ReceiptDate < InvoiceDate`）。
- 币种不一致的收款（收款单币种 ≠ 发票币种，不做汇率换算）。
- 本页关联分摊行超过单次派生上限（2000 行）时，整页收款时效按未知返回。

以上每类都**单独计数与标注**，绝不合并、绝不当作有效收款。

## 5. 界面

客户销项发票台账工具栏与发票详情页新增「⏱️ 收款时效」入口，打开只读视图：
客户 / 开票日期区间 / 关键字 / 每页条数筛选，KPI（符合筛选的已登记发票、已派生收款时效、未知 / 异常本页计数）、
发票明细表（发票身份、客户、开票日期、含税总额、首张 / 末张有效收款单号与日期及间隔天数、可比较已分摊 / 剩余、
异常、说明）。**不提供任何分摊 / 收款 / 作废动作**。

## 6. 测试

`src/ERP.UnitTests/CustomerInvoiceCollectionTimingTests.cs` 覆盖：部分 / 全额分摊、多张收款取最早与最晚有效收款、
收款单取消 / 早于开票日期 / 币种不一致 / 已作废仅作异常列出且不计入、分页有界与稳定排序、
批量取数（固定次数数据集访问、无逐单查库）、只读不写库、业务员数据范围、接口端点与前端接线契约。
全部使用内存数据库，不连接 SQL Server、不启动 API、不执行任何 SQL 或 seed。
