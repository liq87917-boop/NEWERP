# 单证中心：由销售订单 / 装柜清单生成单证与 Excel 导出（ERP-019）

> 本文件说明 ERP-019 交付的「单证中心台账自动化」：**由销售订单与装柜清单生成 / 带入预填单证**，以及**单证台账 Excel 导出**；
> 以及 ERP-030 交付的**单证共享打印**（打印预览 / 直接打印 / 打印设计，见第 10 节）。
> 参考实现：`src/ERP.Api/Controllers/TradeDocumentGeneration.cs`（共享逻辑）、`TradeDocumentController`、`SalesOrderController`、`ContainerLoadingListController`、`src/ERP.Api/wwwroot/js/trade-doc-gen.js`、`src/ERP.Application/Interfaces/TradeDocumentPrintDtos.cs`、`src/ERP.Api/wwwroot/js/trade-doc-print.js`。

## 1. 背景与缺口

ERP-006「全仓功能审计」把「单证中心」判为 **partial**：台账、状态跟踪（待制作 → 已制作 → 已提交客户 → 已使用）与菜单（`doc-center`）已可用，但

1. 只能**手工登记**，没有「由装柜清单 / 销售订单自动生成」；
2. 没有 **Excel 导出**（附件仍是 `FileNote` 文本）。

ERP-019 只补这两个缺口，**不新增任何数据库结构**（`TradeDocument` 实体、`SchemaUpgrader.cs`、`deploy/**`、任何 `.sql` 均未修改）。

## 2. 可用字段与来源留痕口径

单证台账既有字段（`src/ERP.Domain/Entities/TradeDocument.cs`）与两路来源的映射：

| 单证字段 | 销售订单来源 | 装柜清单来源 |
|---|---|---|
| `DocNo` | `{类型前缀}-{订单号}`，冲突自动追加 `-2/-3…` | `{类型前缀}-{装柜清单号}`，同上 |
| `DocType` | 用户勾选（默认 商业发票 + 装箱单） | 用户勾选（默认 装箱单） |
| `IssueDate` | 生成当天 | 装柜日期 |
| `SalesOrderNo` | **来源订单号（留痕）** | 空（清单未关联订单号） |
| `RefNo`（柜号/订舱号） | 空，装柜后人工回填 | **来源柜号（留痕）** |
| `DeclareNo` | 空，报关后人工回填 | 空，报关后人工回填 |
| `CustomerId` / `CustomerName` | 订单客户 + 客户档案名称（无档案时留空） | 清单客户 + 客户档案名称 |
| `Amount` | 订单总额 `TotalAmount` | `0`（装柜阶段金额未定，人工填写） |
| `Currency` | 订单币种枚举名（USD/CNY/EUR/…） | 客户档案币种，为空时 `USD` |
| `DeparturePort` | 空（订单无起运港字段） | 装柜清单 → 预装柜单 → **订柜信息 `DeparturePort`**，缺失留空 |
| `DestinationPort` | 订单目的港文本 → 客户档案目的港 | 订柜信息目的港 → 客户档案目的港 |
| `IssuedBy` / `Copies` | 按类型默认（报关单：报关行·1；产地证：贸促会/海关·2；CI/PL/BL：3…） | 同左 |
| `Status` | 固定 `待制作`（人工确认后才流转） | 固定 `待制作` |
| `FileNote` | 空 | 空 |
| `Remark` | `来源：销售订单 {订单号} ｜ 客户 PO ｜ 合同号 ｜ 贸易条款 ｜ 目的港 ｜ 交货日期 ｜ 定金比例` | `来源：装柜清单 {清单号} ｜ 柜号 ｜ 唛头 ｜ 箱数 ｜ 毛重 ｜ 体积 ｜ 装柜日期 ｜ 装柜备注` |

字段统一按目标列长截断（`MaxLength` 超长不会写入失败）。备注前缀同时也是重复生成守卫的判定依据，**修改文案需同步**。

| 单证类型 | 前缀 | 单证类型 | 前缀 |
|---|---|---|---|
| 报关单 | `CD` | 提单 | `BL` |
| 装箱单 | `PL` | 订舱确认 | `BK` |
| 商业发票 | `CI` | 外汇核销单 | `VR` |
| 形式发票 | `PI` | 其他 | `TD` |
| 产地证 | `CO` | | |

## 5. 重复生成守卫（不产生重复单证）

- **销售订单来源**：同一 `SalesOrderNo` + 同一 `DocType` 视为已生成；
- **装柜清单来源**：同一柜号 `RefNo` **或**备注留痕指向同一装柜清单号，命中同一 `DocType` 即视为已生成（一柜一类单证只应有一份）；
- 批量生成时**任一类型已生成即整体拒绝**（错误码 `RuleConflict`，提示「该…已生成「商业发票」（单证编号 CI-…），不能重复生成」），不会写入半成品数据；
- 已**软删除**的单证不参与判定（删除后可重新生成）；
- 「带入预填」不落库，因此重复校验时机在落库接口上；对话框同时把已生成类型置灰并取消勾选（前端防重）。

其他守卫：来源单据已作废 → `RuleConflict`；未选择类型 → `InvalidParameter`；不在该来源可生成清单内的类型 → `InvalidParameter`（提示可生成类型）；生成后的单证状态为 `待制作`，仍可在单证中心编辑（金额/份数/制作人/备注/状态），**来源留痕保留**。

### 10.3 打印字段口径与缺值语义

字段键与实体属性同名（camelCase），因此「样式设计」勾选顺序（`FieldKeys`）可直接驱动打印顺序，无需二次映射；模板中出现但不属于台账打印字段的键（如 `customerId`）直接忽略。

| 字段键 | 打印页标签 | 取值 / 缺值语义 |
|---|---|---|
| `docNo` | 单证编号 | 台账 `DocNo`（裁剪首尾空白）；无值 → 空白 |
| `docType` | 单证类型 | 原样输出；无值 → 空白 |
| `status` | 状态 | 中文业务状态原样（待制作 / 已制作 / 已提交客户 / 已使用），**不做状态码映射** |
| `issueDate` | 出具/签发日期 | `yyyy-MM-dd`；无值 → 空白 |
| `customerName` | 客户名称 | **仅取台账冗余名称**；历史数据只有 `CustomerId` 时留空，不回查客户档案 |
| `salesOrderNo` | 关联销售订单号 | 来源留痕（见 §2）；无值 → 空白 |
| `refNo` | 关联柜号/订舱号 | 台账 `RefNo`；无值 → 空白（不按单证号推测柜号） |
| `declareNo` | 关联报关单号 | 台账 `DeclareNo`；无值 → 空白 |
| `amount` | 单证金额 | `0.00` 两位小数；`Amount = 0` 视为**未填写金额**（报关单 / 装箱单等本就不含金额口径）→ 空白，不打印 `0.00` |
| `currency` | 币种 | 原样输出；无值 → 空白 |
| `departurePort` | 起运港 | 原样输出；无值 → 空白 |
| `destinationPort` | 目的港 | 原样输出；无值 → 空白 |
| `issuedBy` | 制作人/出证机构 | 原样输出；无值 → 空白 |
| `copies` | 份数 | 正整数；`Copies <= 0` 视为未填写 → 空白（与金额同一口径） |
| `fileNote` | 附件说明/存放位置 | 原样输出；无值 → 空白 |
| `remark` | 备注 | 原样输出；无值 → 空白 |

字段顺序：未保存打印模板时按上表顺序；已保存模板时按模板 `FieldKeys` 顺序（模板中未知键忽略、模板外字段按默认顺序补齐），模板关闭「打印备注」时字段表同步去掉备注列。

**三个入口与共用约定**

| 入口 | 行为 |
|---|---|
| 行操作「打印预览该单证」 | 弹窗展示打印版式并提供「打印」按钮；弹窗内提示「空白字段表示台账中未登记该值」 |
| 行操作「直接打印该单证」 | 不弹预览，直接新窗口输出并调起浏览器打印（预览与直接打印共用同一份打印数据与模板） |

**登记与去重（不破坏既有打印）**：`doc-center` 只登记在 `MODULES`（**未加入 `BILL_CONFIG`**），打印设计的左侧清单按「业务单据优先、基础资料排除同名」去重，因此单证中心只出现一次；打印模板按 `BillType` 隔离，保存单证中心模板不影响报价单 / 形式发票 PI / 销售订单 / 采购订单等既有打印链路。列表工具栏的「🖨 打印预览 / 🖨 打印」仍是共享的**列表批量打印**（打印当前列表行的表格视图），与单条单证版式打印是两种版式，但共用同一打印模板（纸张 / 字号 / 页脚）。

### 10.5 边界与未做项

- **无服务端 PDF / 版式文件**：打印输出走浏览器打印对话框（与既有共享打印一致），不生成服务端 PDF，也不落库打印记录；
- **打印件仍不含明细分行**：打印模型 `HasDetailLines` 在本任务保持 `false`；商业发票 / 装箱单的商品明细行已由 **ERP-051** 落库
  （`TradeDocumentItems`），把明细行纳入打印输出属于 **ERP-052**；
- **打印件不作为权威凭证**：空白即「台账未登记」，系统不会用档案或其他单据补齐单证上的值；金额与份数的 `0` 一律按未填写处理；
- **列表批量打印与单条打印两种版式**：工具栏打印为列表表格视图，行操作打印为单据版式（字段表 + 签署栏），二者共用模板的抬头 / 纸张 / 字号 / 页脚配置。
