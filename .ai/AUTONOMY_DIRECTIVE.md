# NEWERP 全自动开发授权

生效日期：2026-10-04。来源：用户在当前开发对话中的明确授权。

- 持续自主开发，直到整个 NEWERP 按既定四阶段真实验收完成；只在最终交付时通知用户。
- 开发工程选择、失败诊断与整改、任务权限补齐、调度器修复、开发测试环境准备由开发代理自行处理，不要求用户参与日常决策。
- 用户授权读写项目目录内所需源码、测试、文档、任务和调度配置。修改范围必须与具体任务及验证需要相符，保留用户改动和并发开发成果。
- 四阶段顺序保持：统一报表配置平台、全部固定及动态报表迁移、ERP 业务全流程、内置 Agent。当前阶段真实验收通过后才推进后续阶段。
- 失败必须以完整日志为依据落实修复并重新验证；同一失败达到重试上限后停止紧密重复，改用诊断、最小整改和独立工作继续推进。
- 队列不足时继续核实当前阶段的真实缺口和验收条件并补给，不能把补给请求或空转扫描当成业务进展。
- 缺少真实测试环境时主动准备隔离环境；不能伪造验收、绕过外部访问权限或触碰生产数据库。
- 常驻调度器和看守保持运行。ERP-190 已经修复完成；ERP-257/258 保持延后，禁止自动恢复。
- 保留 Git 历史和已有成果，禁止强推、reset、stash、rebase 或丢弃未提交修改。授权不包含生产部署、生产不可逆操作及无关项目操作。

本授权覆盖旧指令中仅允许创建队列文件和必须报告日常错误的限制。任务验收、权限保护、阶段顺序和真实验证要求继续适用。
